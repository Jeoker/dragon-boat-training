# C1 前代码审查与整理

审查日期：2026-09-20。范围为现有 Apps Script、前端 API 客户端及三个页面、Cloudflare C0、测试和接口文档。基于源码与本地测试完成修复；没有部署或操作线上业务数据，没有开始 C1。

## 合并与精简

- Apps Script 路由和方法收敛到一个注册表，自动比对已实现动作清单。
- 业务计划的容量保护、持久化和恢复集中到 `SystemStore.gs`，领域层保留自己的计划格式和业务应用逻辑。
- 管理员成员／训练补读合并为一个受保护工作区读取，删除旧 P2 滚动部署回退和重复读取函数。
- 页面共用“结果未知”的错误判断；删除过时的 P4 未实现提示。
- 增加唯一的 [API 边界约定](../contracts/README.md)，移除接口清单里误导性的 JSON Schema 声明、规格中未实现的接口，以及草稿保存清单里不使用的 `published_revision`。
- Astro 检查排除生成的 `dist`／后端构建文件，避免重复构建时扫描压缩产物。

## 验证与保留边界

当前测试及构建结果统一记录在 [CURRENT-STATUS.md](../CURRENT-STATUS.md)。Node 测试采用现有 Google／DOM 测试环境；CF 测试运行本地 Workers／DO SQLite。它们不等于本轮真实 Google 写入、远端 CF、Safari 或实体手机验收。

本轮保留 Apps Script 的接口版本、旧业务摘要及持久结果格式，没有修改生产端点。排座写接口仍返回最新工作区，不可将它与日志中的不可变结果混为一谈；相关例外已写进 API 约定。C1 必须先落实 DTO／运行时 schema／兼容适配，再迁移完整业务。

原始响应的旧行映射只能检测可识别变化，无法识别同名行交换；C2 的 FormResponse 稳定 ID 和三方冲突处理仍必需。Coach 页面仍有较多状态编排，C1／C3 应随业务域和 API 适配拆分；本轮只合并明确重复逻辑，未做无行为依据的整页重写。

本轮修复的问题没有已知的本地测试阻塞。上线这些修改仍需分别部署 Apps Script、Pages 和 CF staging 并做对应冒烟测试；C4 之前不切换生产写入归属。
