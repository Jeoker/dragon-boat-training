# Epic 职责与验收

产品规则见[README](../README.md)，实现／部署及剩余工作见[当前进度](../CURRENT-STATUS.md)。本目录只维护工作归属、依赖和验收条件，不记录开发阶段的演变。

## 职责

| Epic | 负责交付 | 交接 |
|---|---|---|
| [BE](backend.md) | 规则、契约、权限、存储、持久任务、Google 同步、迁移与恢复 | 给 FE／ADM 提供投影、版本、确定结果和受保护接口 |
| [FE](frontend.md) | 公开页面、共享展示组件、唯一客户端、构建和 Pages 发布 | 给 ADM 提供路由、控件、请求和刷新机制 |
| [ADM](admin.md) | 同一网站中的 Coach Mode、管理会话、确认和冲突交互 | 复用 FE 组件及 BE 授权，不复制业务算法 |

## 共享边界

- BE 决定资格、容量、时间、状态及权限；页面只显示服务器结果。
- FE 维护公开缓存与刷新，ADM 提供管理令牌；退出清理私人数据，受保护缓存不混入公共缓存。
- 训练卡片、报名清单和船位展示共用组件；管理草稿与公开正式版分别投影。
- Google 人工修改及来源审核由 BE 校验／持久化，ADM 显示预览、原内容、缺口和审核结果。
- FE 负责页面端点切换，BE 负责唯一写入权和数据／请求恢复；两端完成同一组业务场景后才交接。

## 依赖与完成条件

当前业务基线和已完成本地能力继续回归；剩余同步／来源／年度门槛完成后接入 C3 管理交互，再执行 C4 影子迁移、对账及受控切换。具体顺序只维护在[迁移计划](../cloudflare-migration-plan.md#c0c4-顺序与阶段门槛)及[当前进度](../CURRENT-STATUS.md#下一轮执行顺序)。

| 验证层 | 责任与完成条件 |
|---|---|
| 规则与契约 | BE 使用可控时钟、并发和原请求重放；动作清单与实现一致 |
| 存储与 Google | BE 验证真实 SQLite 事务、持久任务、逐批回执及恢复；真实 Google 单独验收 |
| 页面 | FE 验证公共流程，ADM 验证管理流程、会话失效、未知结果、冲突及草稿隔离 |
| 双端完整流程 | 页面动作核对服务器及另一端视图；模拟演示不代替真实接口 |
| 发布与交接 | 子路径直达、设备、授权、触发器、资源和恢复有实际证据，缺项保持未完成 |

验证结论统一记录在[验证索引](../tests/CURRENT-VERIFICATION.md)。D5 品牌／语言和 D6 长期身份／跨季历史仅在产品 README 维护；现有交付不提前决定其方案。
